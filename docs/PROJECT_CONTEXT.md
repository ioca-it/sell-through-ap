# Contexto del proyecto — sell-through-ap

## Objetivo

Aplicación de inteligencia de sell-through para analizar inventario, ventas, reposición, EOL, Pareto, Tier, categorías, merma, quiebres e impacto financiero.

## Capacidades actuales

- Maestro de Productos.
- Inventario del Cliente.
- Inventario de Seguridad IOCA.
- Motor EOL.
- Merma y quiebres.
- Reposición sugerida.
- Pareto y Tier.
- Dashboard e informe ejecutivo.
- Exportación CSV y Excel.

## Requisitos permanentes

- Desarrollo AI-First.
- Documentación técnica y funcional.
- Comentarios claros en código.
- Fuentes de información desacopladas.
- Configuration Center.
- Preparación para Dataverse.
- Cambios incrementales y reversibles.
- No mezclar este proyecto con NEXUS.
